# SIWES Guide API

The service behind the SIWES Guide for Miva Open University students.
It is deployed to this Space automatically from the `server` folder of the project repository.

Secrets to set in the Space settings: `GROQ_API_KEY`, `ALLOWED_ORIGIN`, `RECAPTCHA_SITE_KEY`, `RECAPTCHA_SECRET`.
