# Docs index

**Read the relevant file here before making a non-trivial change.** These documents are binding.

| Folder | Holds | Read it when |
|---|---|---|
| [general/](general/) | Glossary, CONTRIBUTING, CHANGELOG | You are new, or a term is unclear |
| [blueprint/](blueprint/blueprint.md) | Blueprint and ADRs (one decision per file) | You change structure, a dependency or the design |
| [product/](product/) | SRS, roadmap, checklist | You add or drop a feature |
| [engineering/](engineering/) | Development guide (run, deploy), coding standards, config reference | You write code or add a setting |
| [qa/](qa/) | Test strategy | You add or change a test |
| [operations/](operations/) | Runbook stub (Phase 3) | You prepare to launch |
| [security/](security/README.md) | Threat model, data map, retention, vendors, draft privacy notice | You touch data, logging or a vendor |

ADRs are numbered and never renumbered or deleted. A reversal is a new ADR that supersedes the old one.
