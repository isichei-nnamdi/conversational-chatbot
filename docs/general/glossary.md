# Glossary

The SIWES terms live in `data/source/segments.curated.json` under `glossary` and are shown in the app. Keep this file in sync with it.

| Term | Meaning |
|---|---|
| SIWES | Student Industrial Work Experience Scheme. Supervised work experience in industry |
| SIWES I / II | The two parts of SIWES, each about 3 months |
| LMS | The Miva learning platform where students upload SIWES documents |
| SCAF form | Student Commencement Acceptance Form, used with the ITF |
| ITF | Industrial Training Fund, the body that coordinates SIWES nationally |
| Acceptance letter | The host organisation's letter accepting the student |
| School supervisor | Miva staff member assigned to supervise and grade |
| Industry-based supervisor | The student's supervisor at the host organisation |
| Segment | One topic of the knowledge base (for example Log Book) |
| Fact | One short statement in a segment, tagged with its source |
| Source tag | `sheet` (coordinator's written answer), `ama` (recording, with timestamp) or `policy` |
| KB | Knowledge base: `server/data/kb.json` |
| Retrieval | Picking the segments most relevant to a question before asking the model |
